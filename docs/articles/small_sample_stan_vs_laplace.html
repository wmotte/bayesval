Robustness check: full-Bayes MCMC vs Cox-Laplace in a small, sparse-event cohort

  • A small, sparse-event, high-censoring cohort pair
  • Cox-Laplace backend
  • Genuine full-Bayes MCMC (fewer pieces: sparse events)
  • Propagate the headline suite on both backends

The agreement between the full-Bayes MCMC model and the Cox-Laplace approximation on Rotterdam→GBSG (see vignette("worked_example")) is a large, well-identified example. It does not by itself support using the fast approximation in the small, sparse-event, high-censoring settings where the framework is most needed. This article fits both backends on one small, high-censoring training cohort (n = 150, ~60% censored, moderate signal) and validates both on an independent small cohort of the same size, so any divergence between the genuine posterior and its large-sample approximation shows up directly in the propagated metrics, and MCMC pathologies (divergences, poor mixing) that a large well-identified fit would not reveal have a chance to appear.

This article requires an rstan toolchain to build and is not run by pkgdown on every site rebuild; it is rendered once and checked in as a static page.

A small, sparse-event, high-censoring cohort pair

sim_covariates <- function(n) {
  tibble::tibble(x1 = stats::rnorm(n), x2 = stats::rbinom(n, 1, 0.4))
}
calibrate_censoring <- function(Tt, target) {
  if (target <= 0) return(0)
  f <- function(c) mean(exp(-c * Tt)) - (1 - target)
  if (f(1e-6) < 0) return(1e-6)
  hi <- 1e-6
  while (f(hi) > 0 && hi < 1e6) hi <- hi * 2
  stats::uniroot(f, c(1e-8, hi))$root
}
dgm_weibull <- function(n, beta, shape = 1.3, rate = 0.15, cens_rate = 0.3) {
  x <- sim_covariates(n)
  lp <- as.numeric(beta["b1"] * x$x1 + beta["b2"] * x$x2)
  U <- stats::runif(n)
  Tt <- (1 / rate) * (-log(U) / exp(lp))^(1 / shape)
  crate <- calibrate_censoring(Tt, cens_rate)
  Cc <- if (crate <= 0) rep(Inf, n) else stats::rexp(n, crate)
  time <- pmin(Tt, Cc); status <- as.integer(Tt <= Cc)
  tibble::tibble(time = time, status = status, x1 = x$x1, x2 = x$x2)
}

N_TRAIN <- 150L; N_VAL <- 150L; CENS <- 0.60
BETA <- c(b1 = 0.70, b2 = -0.50); SHAPE <- 1.3; RATE <- 0.14
horizons <- c(2, 5); h5 <- 2L; tau <- 5

train <- dgm_weibull(N_TRAIN, beta = BETA, shape = SHAPE, rate = RATE, cens_rate = CENS)
val   <- dgm_weibull(N_VAL,   beta = BETA, shape = SHAPE, rate = RATE, cens_rate = CENS)
cat(sprintf("Training cohort: n=%d, %d events (%.0f%% censored)\n",

## Training cohort: n=150, 57 events (62% censored)

## Validation cohort: n=150, 58 events (61% censored)
form <- Surv(time, status) ~ x1 + x2

Cox-Laplace backend

fit_cox <- coxph(form, data = train, x = TRUE, y = TRUE)
ps_cox  <- psurv_external(fit_cox, val, time = "time", status = "status",

Genuine full-Bayes MCMC (fewer pieces: sparse events)

t0 <- Sys.time()

Propagate the headline suite on both backends

suite <- list(
  harrell = metric_harrell_c,
  uno     = function(d, w) metric_uno_c(d, w, tau = tau),
  slope   = metric_cal_slope,
  brier   = function(d, w) metric_brier(d, w)[c(paste0("Brier_t", h5), "IBS")])

post_cox  <- propagate_many(ps_cox,  suite, weights = "bootstrap", seed = 1)
post_stan <- propagate_many(ps_stan, suite, weights = "bootstrap", seed = 1)
tab_cox  <- posterior_table(post_cox)  |> dplyr::mutate(metric = sub("^[^.]+\\.", "", metric))
tab_stan <- posterior_table(post_stan) |> dplyr::mutate(metric = sub("^[^.]+\\.", "", metric))

The full-Bayes MCMC posterior and the Cox-Laplace approximation agree closely on discrimination, calibration slope, and IBS even at this small, sparse-event, high-censoring sample size, and the MCMC diagnostics show no divergences or mixing problems — the fast Laplace approximation is a reasonable stand-in for this framework’s headline metrics, with the caveat that this is one cohort pair, not a systematic sweep (see the Part C coverage study in the source repository for that).
